Architecture & System Design

1. Project Overview

Simple E-Commerce Store is a full-featured, educational web application engineered in strict adherence to Django's Model-View-Template (MVT) pattern. It is designed to serve as a reference implementation for university and portfolio demonstrations, completely free of external CSS/JS frameworks (such as Bootstrap or Tailwind) while providing a clean, responsive user experience using pure semantic HTML5, CSS3, and vanilla JavaScript.

Python 3 Django 4 / 5 SQLite Pure CSS3 Vanilla JavaScript Session Engine Atomic Transactions

2. Data Models & Entity Relationships

The persistence layer is structured across four normalized relational models:

  • Category: Groups catalog products with unique URL slugs and descriptions.
  • Product: Tracks item name, category foreign key, price (DecimalField), stock quantity, and availability flags.
  • Order: Records buyer details, generated order identifiers, total amounts, shipping destinations, and fulfillment statuses (Pending, Processing, Shipped, Delivered, Cancelled).
  • OrderItem: Line items linking an order to specific products with purchase-time price lock-in to protect against subsequent price changes.
+------------------+ +------------------+ | Category | 1 --- * | Product | +------------------+ +------------------+ ^ | +------------------+ +---------|--------+ | Order | 1 --- * | OrderItem | +------------------+ +------------------+

3. Concurrency & Stock Safety

Unlike naive demo stores where overselling can occur when multiple buyers checkout simultaneously, this project wraps inventory deduction inside transaction.atomic() blocks and applies row-level database locks using Product.objects.select_for_update().

User Submits Checkout --> Begin Atomic Transaction --> select_for_update() on cart products (row locks acquired) --> Validate (stock >= cart quantity) [If False]: Rollback & Show Error Message [If True]: Deduct Stock -> Create Order & Items -> Commit Transaction

4. Django Admin & Management Commands

The platform integrates Django's built-in administration panel at /admin/, featuring filterable search tables, inline order item editing, and batch status controls. The database can be seeded automatically via the custom management command:

python manage.py seed_data

This provisions 5 core retail categories, at least 15 sample products with realistic specifications, and an optional pre-configured demo user account.
